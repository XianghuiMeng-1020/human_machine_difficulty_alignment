# Returned formal coding labels

Source archive: `FODE_Blinded_Item_Review_CODED.zip`

These files are the completed formal Stage 1 + Stage 2 codes from two independent raters.

- `Coder_A_Formal_Coding.csv` — 74 formal items
- `Coder_B_Formal_Coding.csv` — same 74 items, independent order originally; this export is aligned by `blind_item_id`

Each row includes the blinded item text plus:

- Stage 1: `rater_answer`, `answer_confidence`, `evidence_demand`, `cannot_judge`, `optional_stage1_note`
- Stage 2: `official_answer_key`, `key_problem`, `stem_problem`, `distractor_problem`, `evidence_problem`, `optional_stage2_note`

These are the original independent ratings. They have not been adjudicated. Do not treat them as final confirmatory results.
